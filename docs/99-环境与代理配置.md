## 网络代理 — 全局走 10.211.55.2:2334

来源:用户指定

```bash
# 当前 shell 临时生效
export http_proxy=http://10.211.55.2:2334
export https_proxy=http://10.211.55.2:2334

# 写入 ~/.bashrc 永久生效(需要时取消注释)
# echo 'export http_proxy=http://10.211.55.2:2334 https_proxy=http://10.211.55.2:2334' >> ~/.bashrc

# git 单独配置代理
git config --global http.proxy http://10.211.55.2:2334
git config --global https.proxy http://10.211.55.2:2334
# 取消: git config --global --unset http.proxy && git config --global --unset https.proxy

# 测试代理连通性
curl -s -x http://10.211.55.2:2334 -o /dev/null -w "%{http_code}\n" https://github.com
```

参数速查:

- `curl -x` — 单次指定代理
- `http_proxy` / `https_proxy` 小写环境变量对大多数 CLI 工具生效
- 部分工具(nmap/漏洞扫描类)不走环境变量,需用 proxychains4(见 06-隧道与代理.md)

注意:APT 已在 `/etc/apt/apt.conf.d/99proxy` 固定走此代理;若换代理需同步修改该文件。

## APT 源 — 已切换 HTTPS(防流量注入)

来源:系统配置(2026-09-15 由明文 HTTP 切换)

```bash
# 查看当前源(已全部 HTTPS)
grep URIs /etc/apt/sources.list.d/kali.sources

# 更新与安装
sudo apt update && sudo apt install -y <包名>

# 查询工具属于哪个包
apt-file search <文件名>        # 需先 apt install apt-file && apt-file update
```

⚠️ 事件记录:2026-09-15 使用明文 `http://http.kali.org` 安装时,下载队列被注入
`https://4943999.com?clickid=…` 广告点击 URL(运营商/中间人对 HTTP 明文传输的
典型注入)。已排查 `/etc/apt/apt.conf.d/` 无本地篡改,属于网络层劫持。
**结论:本机源必须保持 HTTPS,不要改回 http。**

## 练手靶场 — GOAD(⚠ 本机不可部署,需外部宿主)

> **实测结论(2026-09-16)**:本机为 Parallels 虚机,无 `/dev/kvm`、CPU 无 vmx/svm 标志——**嵌套虚拟化不可用,GOAD/VirtualBox 无法在本机运行**。实战校验需外部资源:

```bash
# 部署(约 1-2 小时,含 5 个虚拟机;全程需代理)
export https_proxy=http://10.211.55.2:2334 http_proxy=http://10.211.55.2:2334
git clone https://github.com/Orange-Cyberdefense/GOAD.git ~/tools/src/GOAD
cd ~/tools/src/GOAD && ansible-playbook main.yml   # 按仓库 README 选 provider(virtualbox 最稳)

# 部署完成后,用 domain-setup.sh 接入(对应 10 号文档阶段 0):
#   sudo ~/tools/bin/domain-setup.sh sevenkingdoms.local 192.168.56.10 kingslanding.sevenkingdoms.local
# 再跑:~/tools/bin/ad-sweep.sh 192.168.56.0/24 → 按 10-14 号文档全链路实操
```

注意:GOAD 是故意漏洞百出的域,绝不可暴露到真实网络(仅 Host-Only 网段 192.168.56.0/24);靶机快照先拍好,打崩直接恢复。

**可行的实战路径**:① 16G+ 内存的宿主机跑 GOAD(上述命令照用);② 云 VPS 开嵌套虚化(阿里云/DO 均可,Ubuntu + KVM 装 GOAD,本机 console.sh 的 proxychains 开关远程打);③ HackTheBox/PG 的 AD 靶机(Pro Lab Dante/Zephyr)。
