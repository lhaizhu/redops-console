# 密码攻击

哈希识别、字典制作、离线破解与在线爆破。本文件命令均可直接复制,占位符用尖括号标注(如 `<目标IP>` `<域名>`)。

本文件工具:hashcat、john、hydra、cewl、crunch、hashid、字典资源(seclists/rockyou)

---

## hashcat — GPU 加速的离线哈希破解

来源:apt 包 `hashcat`(/usr/bin/hashcat)

### 常用 -m 哈希类型编号表(内网渗透高频)

| -m | 类型 | 常见来源 |
|----|------|---------|
| 0 | MD5 | Web 应用数据库 |
| 100 | SHA1 | Web 应用、Git |
| 900 | MD4 | NTLM 派生、旧系统 |
| 1000 | NTLM | Windows SAM、secretsdump 导出的 NTDS |
| 3000 | LM | 老系统 SAM |
| 500 | md5crypt($1$) | 旧版 Linux /etc/shadow |
| 1800 | sha512crypt($6$) | 现代 Linux /etc/shadow |
| 3200 | bcrypt($2*$) | Web 应用 |
| 1100 | 域缓存凭据 mscash | 本机注册表缓存 |
| 2100 | 域缓存凭据 mscash2 | Win7+ 注册表缓存 |
| 5500 | NetNTLMv1 | 网络抓取(responder) |
| 5600 | NetNTLMv2 | 网络抓取(responder 抓到的主格式) |
| 13100 | Kerberos TGS-REP(RC4) | Kerberoasting(impacket-GetUserSPNs) |
| 18200 | Kerberos AS-REP(RC4) | AS-REP Roasting(无预认证账户) |
| 22000 | WPA-PMKID+EAPOL | WiFi 抓包(hcxpcapngtool 转换) |

### 字典攻击与规则变形

```bash
hashcat -m 1000 ntlm.txt /usr/share/wordlists/rockyou.txt -O                  # NTLM + rockyou,-O 优化内核提速
hashcat -m 1000 ntlm.txt /usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best66.rule -O   # 叠加规则变形,命中率更高
hashcat -m 3200 bcrypt.txt /usr/share/wordlists/rockyou.txt -w 3              # bcrypt 极慢,-w 3 拉满工作负载
```

### 掩码暴破(-a 3)

```bash
hashcat -m 1000 ntlm.txt -a 3 ?d?d?d?d?d?d?d?d -O                            # 8 位纯数字(生日/手机尾号)
hashcat -m 1000 ntlm.txt -a 3 -1 ?l?d ?1?1?1?1?1?1?1?1 -i --increment-min 6  # 小写+数字,从6位递增到8位
hashcat -m 1800 shadow.txt -a 3 ?u?l?l?l?l?d?d?d?s                          # 常见强口令形态:大写开头+尾加数字符号
```

### 结果查看与设备控制

```bash
hashcat -m 1000 ntlm.txt --show                                              # 查看 potfile 里已破解的明文
hashcat -m 1000 ntlm.txt --username /usr/share/wordlists/rockyou.txt         # 哈希文件为 用户名:哈希 格式时忽略用户名
hashcat -I                                                                   # 列出 OpenCL 设备(无 GPU 只会看到 CPU)
hashcat -m 1000 ntlm.txt /usr/share/wordlists/rockyou.txt -D 1               # 强制 CPU(虚拟机/驱动报错时)
hashcat --session adproj -m 1000 ntlm.txt /usr/share/wordlists/rockyou.txt   # 命名会话,中断后 hashcat --restore --session adproj 续跑
```

参数速查:

- `-m <编号>`:哈希类型,见上表;全量表用 `hashcat --help` 查
- `-a <模式>`:0=字典 1=组合 3=掩码 6=字典+掩码 7=掩码+字典
- `-r <规则文件>`:字典变形规则,本机在 /usr/share/hashcat/rules/(best66/dive/rockyou-30000)
- `-O`:优化内核,更快但限制明文最大长度,超长密码别用
- `-w <1-4>`:工作负载档位,3/4 会明显卡桌面
- `-D 1` / `-D 2`:设备类型 1=CPU 2=GPU;`-d <N>` 选具体设备号
- `-i`(`--increment`):掩码长度递增,配 `--increment-min/-max` 控制范围
- `--show`:显示已破解结果(历史记录在 ~/.local/share/hashcat/hashcat.potfile)
- `--username`:自动剥离 `用户名:哈希` 中的用户名前缀
- `-S`:慢哈希(bcrypt 等)走标准内核跑字典,兼容性最好

注意: 虚拟机无 GPU 直通时只能 `-D 1` 跑 CPU,速度差 1-2 个数量级;13100/18200 只适用 etype 23(RC4)票据,AES 票据用 19600/19700;跑之前先 `--show` 查 potfile 避免重复劳动。

## john — 老牌离线破解,加密文件/密钥口令强项

来源:apt 包 `john`(/usr/sbin/john,Kali 为 jumbo 版,自带 zip2john 等提取脚本)

### 系统/域密码哈希

```bash
sudo unshadow /etc/passwd /etc/shadow > unshadow.txt                          # Linux:先合并 passwd+shadow
john --wordlist=/usr/share/wordlists/rockyou.txt --rules unshadow.txt         # 字典+规则破解
john --format=NT --wordlist=/usr/share/wordlists/rockyou.txt --rules ntlm.txt # Windows NTLM 哈希文件
```

### 加密压缩包与密钥口令(先提取哈希)

```bash
zip2john <文件.zip> > zip.hash && john --wordlist=/usr/share/wordlists/rockyou.txt zip.hash       # ZIP 口令
rar2john <文件.rar> > rar.hash && john --wordlist=/usr/share/wordlists/rockyou.txt rar.hash       # RAR 口令
ssh2john <私钥文件> > ssh.hash && john --format=ssh --wordlist=/usr/share/wordlists/rockyou.txt ssh.hash   # SSH 私钥口令
keepass2john <数据库.kdbx> > kp.hash && john --wordlist=/usr/share/wordlists/rockyou.txt kp.hash  # KeePass 主密码
```

### 结果查看与续跑

```bash
john --show zip.hash      # 显示某哈希文件已破解的结果
john --restore            # 从上次中断处继续
john --list=formats       # 列出全部支持格式(数百种)
```

参数速查:

- `--wordlist=<文件>`:字典路径
- `--rules`:启用字典变形(大小写/数字后缀/常见替换)
- `--format=<格式>`:NT、sha512crypt、md5crypt、zip、rar、ssh、keepass 等
- `--mask=<掩码>`:内置掩码暴破(如 `--mask=?u?l?l?l?d?d?d?d`)
- `--show`:查看破解结果
- `--restore`:继续中断的任务
- `--session=<名>` / `--fork=<N>`:会话管理 / 多核并行
- `--users=<用户>`:只破解指定账户
- `--stdin`:从管道读字典(配 crunch 实时生成免落盘)

注意: zip/rar/ssh/keepass 必须先用对应 `*2john` 提取哈希文件再喂给 john;破解 SSH 私钥口令后 `chmod 600 <私钥>` 即可 `ssh -i` 直接登录;格式名以 `--list=formats` 为准。

## hydra — 在线多协议登录爆破

来源:apt 包 `hydra`(/usr/bin/hydra)

### 基础爆破(SSH/SMB/RDP)

```bash
hydra -l root -P /usr/share/wordlists/rockyou.txt -t 4 -f <目标IP> ssh    # SSH:单用户+大字典,限4线程防断连
hydra -L users.txt -P passwords.txt <目标IP> smb                          # SMB:用户表+密码表交叉爆破
hydra -L users.txt -P passwords.txt -M hosts.txt rdp                      # 同一套表批量打多台主机的 RDP
```

### Web 表单与自定义端口

```bash
hydra -l admin -P passwords.txt <目标IP> http-post-form "/login.php:user=^USER^&pass=^PASS^:用户名或密码错误"
hydra -l admin -P passwords.txt <目标IP> -s 8080 http-get /manager/html   # 指定端口的 HTTP Basic 认证
hydra -l <用户名> -p <密码> <目标IP> mysql                                 # 单密码验证型服务(验证泄漏凭据)
```

### 效率与收尾

```bash
hydra -L users.txt -P passwords.txt -e nsr -f <目标IP> ssh               # 追加空密码/用户名同密码/反向,成功即停
hydra -l root -P passwords.txt -t 4 -vV -o found.txt <目标IP> ssh        # -vV 实时显示尝试,-o 结果落盘
hydra -R                                                                  # 恢复中断任务(hydra.restore)
```

参数速查:

- `-l / -L`:用户名 / 用户名列表文件
- `-p / -P`:密码 / 密码列表文件
- `-t <N>`:并发线程,默认 16;SSH 建议 4,过高易断连
- `-f` / `-F`:单个目标成功即停 / `-M` 批量时任一成功即停
- `-s <端口>`:指定非默认端口
- `-S`:走 SSL(https、ldaps 等)
- `-e nsr`:n=空密码、s=用户名当密码、r=反向(密码当用户名)
- `-M <文件>`:目标主机列表,一行一个
- `-vV`:显示每次尝试详情
- `-R`:恢复上次中断的任务

注意: 在线爆破动静大,域账号锁定阈值常见 5-10 次,域环境改用 05 文档的 netexec 低频喷洒;http-post-form 第三段默认是"失败关键字",可写 `S=<成功关键字>` 按成功判定,关键字务必从真实登录失败响应里原样复制。

## cewl — 爬取目标网站生成定制字典

来源:apt 包 `cewl`(/usr/bin/cewl)

### 基础爬取

```bash
cewl http://<目标域名> -d 2 -m 5 -w site_words.txt          # 爬2层,输出长度≥5的词
cewl https://<目标域名> -d 3 -m 4 -w site_words.txt -e --with-numbers   # 深爬3层,带邮箱和含数字的词
```

### 进阶选项

```bash
cewl http://<目标域名> -w site_words.txt -a --lowercase    # 收集网页 meta/文件元数据,全部转小写
cewl http://<目标域名>/login -d 1 -w site_words.txt --auth_type basic --auth_user <用户名> --auth_pass <密码>   # 需认证的页面
```

参数速查:

- `-d <层数>`:爬取深度,默认 2
- `-m <字符数>`:最短词长,默认 3;`-x <字符数>` 最长词长
- `-w <文件>`:字典输出文件
- `-e`:同时收集邮箱地址(配 `--email_file` 单独落盘)
- `-a`:包含网页 meta 与文件元数据(配 `--meta_file`)
- `--with-numbers`:保留含数字的词
- `--lowercase`:全部转小写(密码变形交给 --rules)
- `--auth_type/--auth_user/--auth_pass`:basic/digest 认证
- `-c`:显示每词出现次数(判断权重)
- `-v`:详细输出

注意: cewl 字典配合 hashcat/john 的 `--rules` 使用命中率远高于通用字典;目标站大时控制 `-d`,全站爬取既慢又容易触发告警。

## crunch — 按规则生成特定格式字典

来源:apt 包 `crunch`(/usr/bin/crunch,字符集表 /usr/share/crunch/charset.lst)

```bash
crunch 11 11 0123456789 -o phone.txt                        # 11位纯数字(手机号全空间,约1亿条)
crunch 11 11 0123456789 -t 138@@@@@@@@ -o cm.txt            # 已知号段138+8位数字,@是占位符
crunch 8 8 -f /usr/share/crunch/charset.lst lalpha-numeric -o ln8.txt    # 字符集表:小写字母+数字
crunch 6 12 -o START -b 500mb -z gzip                       # 每500MB分一个卷并gzip压缩,文件名自动编号
```

参数速查:

- 位置参数 `最小长度 最大长度 [字符集]`:字符集缺省为全部可打印字符
- `-t <掩码>`:@=小写字母、`,`=大写字母、%=数字、^=符号
- `-f <charset.lst> <集合名>`:使用字符集表(numeric/lalpha/ualpha/mixalpha-numeric 等)
- `-o <文件>` / `-o START`:输出文件;START 配合 -b/-c 自动分卷编号
- `-b <大小>`(kb/mb/gb) / `-c <行数>`:分卷阈值,需 `-o START`
- `-z bzip2|gzip|lzma|xz|7z`:边生成边压缩
- `-s <起始串>`:从指定字符串开始(断点续生成)
- `-p <字符…>`:已知字符的全部排列组合(如 `-p a,b,1,2`)
- `-d <n>@,%^`:限制相同字符最大连续次数(如 `-d 2@` 小写不连续超2个)

注意: 体积指数膨胀(8 位小写全空间约 2TB),生成前先看 crunch 打印的体积预估;配合管道免落盘:`crunch 10 10 0123456789 | john --stdin --format=<格式> <哈希文件>`。

## hashid — 识别哈希类型与对应破解模式

来源:apt 包 `hashid`(/usr/bin/hashid)

```bash
hashid -m -j '<哈希串>'       # 识别并同时给出 hashcat 模式号(-m)和 john 格式(-j)
hashid -e -m -j '<哈希串>'    # 扩展模式:连加盐变体一起列出
echo '<哈希串>' | hashid -m   # 管道输入,适合批量
```

参数速查:

- `<输入>`:待识别的哈希串(位置参数,缺省从 stdin 读)
- `-m`:输出对应的 hashcat 模式编号
- `-j`:输出对应的 john 格式名
- `-e`:扩展候选,包含加盐版本
- `-o <文件>`:结果写入文件

注意: 输出是按可能性排序的候选列表而非唯一答案,需结合长度(NTLM 恰为 32 位 hex)和来源场景人工确认,选错 `-m` 会白跑一遍。

## 字典资源 — seclists 与 rockyou 速查

来源:apt 包 `seclists`(/usr/share/seclists,另有软链 /usr/share/wordlists/seclists);rockyou 由 Kali 预置

### rockyou 解压与使用

```bash
sudo gunzip -k /usr/share/wordlists/rockyou.txt.gz    # 解压出 rockyou.txt(约1434万条,-k 保留原压缩包)
wc -l /usr/share/wordlists/rockyou.txt                # 确认条目数
zcat /usr/share/wordlists/rockyou.txt.gz | wc -l      # 不解压直接统计(管道喂给工具也一样)
```

### seclists 目录定位

```bash
ls /usr/share/seclists/Passwords/Common-Credentials/   # 常用密码字典都在这
ls /usr/share/seclists/Usernames/ /usr/share/seclists/Discovery/DNS/   # 用户名 / 子域字典
```

路径速查(本机实际存在):

- `/usr/share/wordlists/rockyou.txt(.gz)` — 1434 万泄漏密码,万能默认字典
- `/usr/share/seclists/Passwords/Common-Credentials/10k-most-common.txt` — 万条常用密码
- `/usr/share/seclists/Passwords/Common-Credentials/best1050.txt`、`2023-200_most_used_passwords.txt` — 精选小字典(喷洒首选)
- `/usr/share/seclists/Passwords/Common-Credentials/top-20-common-SSH-passwords.txt` — SSH 专用
- `/usr/share/seclists/Usernames/top-usernames-shortlist.txt`、`xato-net-10-million-usernames.txt` — 用户名表
- `/usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt`、`bitquark-subdomains-top100000.txt` — 子域枚举
- `/usr/share/seclists/Discovery/Web-Content/common.txt` — Web 目录/文件爆破
- `/usr/share/seclists/Fuzzing/4-digits-0000-9999.txt` 等 — 纯数字 PIN
- `/usr/share/hashcat/rules/`(best66.rule、dive.rule、rockyou-30000.rule)— hashcat/john 通用规则

注意: 工具大多要解压后的纯文本字典;先跑小字典(best1050/10k)再上 rockyou,时间成本低得多;面对国内目标,cewl 自建字典 + 规则往往收益最高。
